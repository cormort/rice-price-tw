# 台灣糧價與公糧收購 — 互動分析

民國 99–115 年（西元 2010–2026）台灣稻穀市價、白米零售／躉售價格，與公糧三級收購價、收購量的互動分析。

## 線上瀏覽

GitHub Pages：https://cormort.github.io/rice-price-tw/

## 內容

- **市價趨勢** — 15 條價格序列（稻穀／白米躉售／白米零售 × 5 稻種）的全國月平均，可切換期間與指數化
- **公糧 vs 市價** — 市場稻穀價 vs 公糧計畫／輔導／餘糧收購含補助名目價，另附一張「價差」圖直接標出**交叉年**（該級距被市價追上的那一年：餘糧 100 年、輔導 113 年、計畫從未翻負）
- **分級機制** — 115 年 1 期分級實證：**配額上限 vs 實際收購量並排**，配額使用率直接標在長條上（計畫 97.2%、輔導 70.5%、餘糧 2.4%）；另附作物結構（對數刻度，因量差達 4 個數量級）與 114 年改制
- **114 年改制** — 配額重分配（總量不變、餘糧 3,000→400 公斤/公頃）的期別實證
- **統計檢驗** — 相關係數（附 95% CI 與 Spearman ρ）、散佈圖、期作面板（1／2 期**拆成兩張小圖**，因兩期量差一個量級）、縣市雙向固定效果、時代對比（β 係數圖 ＋ 殘差散佈）、係數縮水五步階梯、100 年調價中斷時間序列＋假政策年、留一年度與價差率穩健性
- **每個分析都附兩段說明** — 「白話講」（這個數字在問什麼）與「政策意涵」（對收購價、配額、預算與政策評估的實務意義；維持不宣稱因果的立場）。114 年改制另附財政成本估算：平均收購單價 24.18 → 25.60 元／公斤，支出約 +2.2 億元（同法估 113 年與官方支出差 0.1%）
- **資料與方法** — 來源、單位換算、配額面積推算法與注意事項

**缺值處理**：原始月資料若價格為 `0`（應代表無有效報價，非官方資料錯誤），一律視為缺值——不納入年度平均、走勢圖不畫點（缺值兩端仍以直線相連，`spanGaps: true`）、CSV 留空。已知 1 筆：112 年 12 月「稻穀_硬秈(在來)」；若誤當 0 計入，112 年硬秈年均價會由 25.05 被拉低到 22.97 元／公斤。作物結構圖因使用對數刻度，2 筆 0 值以文字標示而非長條。

**全站單位可切換**（元／公斤 ⇄ 元／百公斤），內部一律以 元／公斤 計算。

**配色**：全站不使用紅／綠對比（紅綠色盲最常見的陷阱）。正向／顯著一律用藍（`#1f5fa8`／`#1f6feb`），
負向／不顯著用紅（`#c0392b`），市場價格用中性深灰藍（`#2c3e50`）以免與語意色混淆；
品種色序為 藍／橘／琥珀／紫／藍綠。文字色皆通過 WCAG AA（在 `#fffbf0` 底上 ≥4.5:1）。

## 主要發現

1. **縣市／期作層級的價格效果不穩健（本站最重要的一組結果）** — 全國年度資料上「輔導價差 ↔ 收購量」r = +0.65、差分後仍有 +0.36；但加上縣市與期作固定效果後，β = 0.049（t = 1.65，95% CI 跨 0），組內 R² 僅 0.006。同一個級距換一種切法就翻盤，最合理的讀法是年度關聯主要在度量「年份」而不是「價格」。
2. **價格效果對估計視窗極度敏感** — 同一個模型在 88、90–98 年（舊制）β = 0.502（顯著）、99–113 年（新制）β = 0.049（不顯著），交互作用 −0.453（t = −3.99）。
3. **係數是逐步縮水的** — 0.50 → 0.32 → 0.19 → 0.12 → 0.05，每一步都能歸因到一個具體動作（加縣市 FE／加期作 FE／除以產量／補齊樣本）。
4. **114 年改制：總量不變、結構反轉** — 全年合計 −2.6%，但計畫＋輔導 +28.6%、餘糧 −99.6%。
5. **「量少」不等於「配額用滿」** — 115 年 1 期餘糧只收 594 公噸，僅用掉配額上限（約 24,867 公噸）的 2.4%；反觀計畫用掉 97.2%。**配額不是約束條件，本站不宣稱知道餘糧崩跌的真正原因。**
6. **總產量與收購量的同期關聯最強** — r = +0.83（99–113 年），但屬機械性（沒有稻穀就沒有公糧）。
7. **100 年調價是最明顯的政策前後差異** — 每公斤調升 3 元，收購量 19.1 萬 → 38.6 萬公噸（+102%），但同期總產量亦增加約 15%，不能全部歸因於調價。中斷時間序列顯示計畫＋輔導收購占比在 100 年跳升約 12.8 個百分點，但假政策年 93、103 年也各有顯著（下降）斷點。
