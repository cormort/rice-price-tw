# 台灣糧價與公糧收購 — 互動分析

民國 99–115 年（西元 2010–2026）台灣稻穀市價、白米零售／躉售價格，與公糧三級收購價、收購量的互動分析。

## 線上瀏覽

GitHub Pages：https://cormort.github.io/rice-price-tw/

## 內容

- **市價趨勢** — 15 條價格序列（稻穀／白米躉售／白米零售 × 5 稻種）的全國月平均，可切換期間與指數化
- **公糧 vs 市價** — 市場稻穀價 vs 公糧計畫／輔導／餘糧收購實質價（含烘乾補助 2 元/公斤）
- **分級機制** — 含 114 年改制實證、115 年 1 期分級實證、期作 × 收購類型同期比較
- **統計檢驗** — 相關係數、散佈圖與反例
- **資料與方法** — 來源、單位換算、解讀限制與注意事項

**全站單位可切換**（元／公斤 ⇄ 元／百公斤），內部一律以 元／公斤 計算。

## 資料來源

| 資料 | 來源 |
|---|---|
| 市價（月平均，99–115 年） | 農業部農糧署「糧價、糧商及當旬公糧收購數量資料查詢系統」（糧價年平均-依月份） |
| 公糧收購價格 | 農糧署各期作公告（計畫 26／輔導 23→24.5／餘糧 21.6 元/公斤；秈糯各少 1 元） |
| 公糧收購量（99–113 年） | 農業部提供，立法院報告表 3-2／3-3 |
| 公糧收購量（114 年）＋期作拆解（99–114 年） | 農業部「農業統計資料查詢」—「農業部計畫、輔導及餘糧收購稻穀情形」（CI03） |
| 115 年 1 期分級收購量 | 農糧署公糧稻穀收購情形旬報表 |

> **來源交叉驗證**：農業統計資料查詢（CI03）與立法院表 3-3 逐筆比對，**99–113 年 15 個年度有 14 個完全相同**（僅 100 年差 0.6%，屬官方修訂），故以 CI03 補上 114 年。

> 註：公糧收購價格只分「稉種」與「秈種及糯種」兩個價格別，市價則有 5 個品種，因此品種對照時秈／糯共用同一公糧價。收購量資料本身**不含品種維度**。

## 主要發現

1. **「市價好、公糧少」方向正確但解釋力弱** — 市價 vs 收購量 r = −0.20；因為總量主要由產量決定（r = +0.85）。
2. **換成價差，相關度跳升** — 「公糧輔導實質價（含補助）− 市價」 vs 收購量 r = +0.64。農民看的是划不划算。
3. **機制是逐級距發生的** — 115 年 1 期餘糧實質價 23.6 元/公斤 低於市價 26.14，收購量僅 594 公噸（幾乎歸零）。
4. **114 年改制是「總量不變、配額重分配」，且已有實證** — 113 → 114 年：計畫 158,167 → 224,540 公噸（+42.0%）、輔導 +1.5%、餘糧 75,866 → **305 公噸（−99.6%）**，但全年合計 312,080 → 304,055 公噸（**−2.6%**）。總量幾乎沒動，結構整個翻過來。
5. **餘糧崩跌的主因是制度，不只是價差** — 餘糧配額被砍 87%（3,000→400 公斤/公頃），價差只是讓農民願意改填計畫與輔導。
6. **公糧收購極度集中一期作** — 114 年 1 期占全年 91.4%（113 年 95.5%）。這也是「115 年 1 期 ≈ 114 年全年」不奇怪的原因；本站一律採同期作比較。
7. **114 年稻作總產量官方年度表尚未收錄** — 故 114 年不列入收購占比與產量相關統計（相關分析仍涵蓋 99–113 年）。
